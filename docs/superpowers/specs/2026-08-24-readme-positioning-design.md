# README 定位与发布说明设计

## 目标

让公开仓库 README 同时回答三个问题：这个项目是什么、相比直接使用上游有什么实际价值、以及它与上游 Harness 的边界是什么。

## 内容方案

- 首屏使用一句话定位：官方 DeepSeek Harness 的 Windows 桌面入口与插件增强层。
- 新增“为什么选择这个项目”对比表，比较直接使用上游命令行入口与本项目 Windows 包装器在启动方式、CPA/CLIProxyAPI、子智能体设置、会话续接和 Windows 兼容上的差异。
- 新增“核心卖点”和“适合谁”，只描述仓库中已有且可由测试或配置核验的能力，不声称官方认证、性能领先或商业签名。
- 新增“与上游的关系”说明，明确核心运行能力来自官方 npm 包，本项目通过 Electron 包装器、本地插件和兼容性重写提供桌面体验；上游刷新必须执行能力分类和回归门禁。
- 保留现有 CPA、续接 Markdown、开发、安全和版本更新内容，并把当前 RC 安装包入口放到发布说明中。

## 发布边界

- README 和设计文档进入 Git。
- `win-desktop/dist/` 中的安装包不进入 Git 历史；如果创建 GitHub Release，则只作为 Release 附件上传。
- 发布前从 `win-desktop` 运行 `npm run verify:upstream`，并检查公开仓库 diff 不含凭据、会话、日志、截图、导出文档或本地上游源码。
