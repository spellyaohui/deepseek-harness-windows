# v0.1.14-desktop.10

- Replaces the long captain protocol with a lifecycle-first state machine. The complete built-in `software-delivery` prompt is 3,353 characters while retaining role reasoning, staged approval, dependency scheduling, attempt/reassignment safety, quality gates, halt/resume, cleanup, and deployment-confirmation rules.
- `agent_teams_create` now treats a missing, empty, or whitespace-only optional `profile` as omitted and creates an ad-hoc Team. It never selects a default Profile.
- Unknown non-empty Profile names remain strict and fail before durable state creation or member spawning. The tool schema lists the configured Profile names and tells models to omit the property when none is requested.
- Added prompt-budget, lifecycle, zero-write, and zero-spawn regressions for these boundaries; strict V2 Profile/Team persistence and role-level Provider/model/reasoning behavior are unchanged.
