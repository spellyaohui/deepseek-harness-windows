# @nanmicoder/dsh-agent-teams v0.1.15-desktop.5

## Changes

- Added one durable-session subagent gateway for continuable child start, send, interrupt, retirement, and drain operations.
- Gateway admission resolves the exact live Agent and rejects stale handles, same-ID pseudo-handles, and retired children before any underlying operation starts.
- Per-child locks serialize delivery, retirement, and drain, closing the retirement race while preserving bounded cleanup.
- Kept role-level Provider/model/reasoning selection authoritative under RC.1 `agent/created` for first, concurrent, and cold-resumed requests.
- Added focused gateway and RC.1 request-route regressions.
