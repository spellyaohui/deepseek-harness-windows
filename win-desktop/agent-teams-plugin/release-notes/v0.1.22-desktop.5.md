# AgentTeams v0.1.22-desktop.5

Pending local desktop release; upstream remains v0.1.22 and Harness remains 0.2.0-rc.2.

- Adds an independent temporary subagent default Provider/model and reasoning policy under AgentTeams settings. Description/prompt-only captain calls in Team mode use this policy without creating the four Profile roles.
- Supports concurrent and repeated delegations within existing member limits, through real Team tasks and the durable child gateway. Existing Profile and native-mode routing stay independent.
- Unavailable configured routes fail before persistent writes; changing defaults preserves existing members and reuses only compatible idle temporary members.
- Saves the complete policy atomically through SettingsForms CAS. Cancelling or editing a failed draft clears the old retry payload.
- Retains twenty real-runtime offline compatibility regressions, serialized settings/client checks and real Loader/ConfigEditor save/restart, stale-revision and Home/CLI overlay refusal tests.
