# v0.1.14-desktop.12

This Windows fork release adapts AgentTeams to DeepSeek Harness
`dsh-v0.1.2-alpha.2` without installing the upstream experimental AgentTeams
packages.

## Changed

- Adapt the client activity, settings, session-navigation and model-catalog
  seams to Alpha.2 Remote, Slot and session interfaces.
- Port the verified wait, identity-scoping, Revision/CAS and event-recovery
  structure required by the maintained desktop fork.
- Preserve role-owned Provider/model/reasoning policy, strict Profile/Team V2,
  quality gates, compact read-only status, explicit mailbox acknowledgement,
  captain-only recovery wake-up, Team/Native routing and desktop Profile
  editing.
- Keep all rc.26+ lifecycle and model-facing error-governance regressions.

No historical Team/Profile migration layer is added. AUTO remains outside this
package and its startup graph.

# v0.1.14-desktop.12（Windows fork）

本版本将 AgentTeams 适配到 DeepSeek Harness `dsh-v0.1.2-alpha.2`，但不把上游
实验性 AgentTeams 包直接加入安装依赖。

## 变更

- 适配 Alpha.2 的 Remote、Slot、会话导航、活动面板和共享模型目录接口。
- 迁入本地 fork 所需且已经验证的 wait、身份作用域、Revision/CAS 与事件恢复结构。
- 保留角色级 Provider/模型/思考策略、严格 Profile/Team V2、质量门禁、紧凑只读
  状态、显式邮箱确认、队长恢复唤醒、Team/Native 路由和桌面 Profile 编辑。
- 保留 rc.26 以来全部生命周期与模型调用错误治理回归。

不新增旧 Team/Profile 迁移层；AUTO 不进入本插件及启动图。
