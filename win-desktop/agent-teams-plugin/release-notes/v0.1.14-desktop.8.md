# v0.1.14-desktop.8

- A running Team now returns a structured, non-error response when a model mistakenly calls `agent_teams_edit_plan`; the approved plan remains immutable and the response points to `agent_teams_create_task`, `agent_teams_send_message`, `agent_teams_reassign_task`, and `agent_teams_status`.
- The staged member editor preserves `target-default`, `route-aware`, and `explicit` reasoning policies; switching away from `explicit` clears the old explicit effort, and non-explicit modes never submit a materialized effort as a new override.
- Staged task edits can replace and clear the complete quality contract, including `kind`, `objective`, `inScope`, `outOfScope`, `acceptance`, `verify`, `deliverables`, and coverage fields. Host payloads reject any list containing non-string items.
- Implementation and repair deliverables must be covered by `inScope` before the task can be staged or approved.
- Completing an implementation or repair with `changedPaths: []` requires `noChangesReason`, and declared deliverables cannot be hidden behind an empty changed-path report.
- Added regressions for running-plan misuse, explicit-to-inherited policy switching, Host list validation, complete staged contract persistence/clearing, deliverable scope, and no-change evidence.
