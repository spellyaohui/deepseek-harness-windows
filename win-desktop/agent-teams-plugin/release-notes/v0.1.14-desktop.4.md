# AgentTeams v0.1.14-desktop.4

This Windows fork release keeps the upstream AgentTeams v0.1.14 lifecycle and
quality validation while making durable task reads compatible with older or
upstream writers that materialize omitted optional quality fields as sentinels.

## Fixed

- Cold-resume now treats `round: 0` and blank `objective`, `reviewedTaskId`, or
  `sourceTaskId` values as omitted. These are the only values normalized;
  meaningful quality contracts and invalid non-sentinel values remain subject
  to the strict durable-state validator.
- The regression reproduces the running-team failure that surfaced as
  `invalid AgentTeams state` while creating a later task, without modifying
  live `.agent-teams` state.

## Verification

- `pnpm test` passes in `win-desktop/agent-teams-plugin`.
- `npm run verify:upstream` passes from `win-desktop` without installing
  dependencies or accessing the network.
- The Windows wrapper x64 NSIS and ZIP artifacts are rebuilt and inspected
  before distribution.
