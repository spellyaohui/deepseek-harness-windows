## Upstream baseline

- Upstream package/tag: `@nanmicoder/dsh-agent-teams@0.1.17-rc.1` /
  `v0.1.17-rc.1`.
- Fixed source commit: `2e59da17918558cfa3bf91d30d40f737509cca0c`.
- Recommended Harness host: `0.1.5-rc.1`; explicitly retained legacy host
  lines are `0.1.2-rc.1`, `0.1.2-alpha.5`, and `0.1.2-alpha.2`.

## Merge result

- Uses the 0.1.5 delivery and Session v3 architecture. Team work is delivered
  through the host queue path; session navigation and activity surfaces use
  the current upstream behavior.
- The durable-session gateway remains the only admission path for child start,
  delivery, steer, interrupt, retirement, and drain. It rejects stale or
  same-ID pseudo-handles and serializes operations per child.
- Keeps only local capabilities that upstream does not provide: role-level
  Provider/model/reasoning policy, strict V2 persistence, quality contracts,
  shared model catalog, Team/Native routing, authenticated Web routes, Profile
  editor integration, and desktop-only compatibility regressions.
