# v0.1.14-desktop.7

- Made `agent_teams_status` a clean read-only probe for sessions that have not created or joined a Team. It now returns `active: false` and renders `No active Team for this session.` instead of raising `you do not lead or belong to any active team yet`.
- Kept `agent_teams_claim_task`, `agent_teams_update_task`, and `agent_teams_send_message` behind the strict participant boundary, so the probe change does not grant inactive sessions any Team mutation or messaging authority.
- Allowed an implementation task to be queued in a running Team behind an active requirements dependency. The dependency must be explicit, and dispatch remains blocked until requirements completes with `verdict=pass`.
- Added regressions covering the inactive status result/rendering and running-phase requirements dependency queueing.
