# v0.1.14-desktop.11

- `agent_teams_status` now defaults to a read-only compact summary. It keeps quality-critical task/dependency/attempt/attempt_id/verdict/findings, coverage, delivery blockers, and new mailbox information while omitting repeated task outputs and stable route/profile details.
- Unchanged summaries collapse to a small heartbeat based only on summary-visible fields. Use `detail="full"` when reviewing complete reports, verification evidence, Provider/model details, or Profile protocol.
- Status inspection no longer wakes members or acknowledges mail by default. Set `acknowledge=true` only after processing displayed mailbox entries; captain recovery requires explicit `wake="recover"`. Ordinary creation, approval, task update, and member-idle scheduling remains event-driven.
- Added regressions for read-only mailbox behavior, explicit acknowledgement, compact/full rendering, unchanged heartbeats, captain-only recovery wake-up, and preservation of the existing lifecycle, quality-gate, and stress behavior.
