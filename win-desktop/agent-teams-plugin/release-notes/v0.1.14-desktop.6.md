# v0.1.14-desktop.6

- Fixed `agent_teams_create_task` calls from non-GPT models that supply blank optional strings. Blank `objective`, `reviewedTaskId`, and `sourceTaskId` values are omitted before persistence, so the resulting Team remains readable by strict V2 validation.
- Made `agent_teams_delete` idempotent when the captain has no active Team. A cleanup probe now returns a clean no-op instead of `you are not leading any team yet`.
- Kept strict `schemaVersion: 2` Profile/Team loading and role-level Provider/model/reasoning authority. This release adds no legacy migration or old-conversation compatibility layer.
