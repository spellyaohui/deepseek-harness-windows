# v0.1.15-desktop.1

This Windows fork refreshes its AgentTeams upstream provenance to fixed commit
`232a338fc9a0d393f118912386f67e7f3a6c67d6` / package `0.1.15`.

## Changed

- Normalize blank optional task fields only at new model-facing tool-input
  boundaries. Strict V2 durable reads remain fail-closed; no historical Team
  or Profile migration layer is added.
- Settle only final member `agent/error` events that still match the current
  Team, member, task, attempt and `attemptId`. Duplicate, stale, reassigned,
  removed-member and replaced-Team events are ignored without writes.
- Persist a bounded, sanitized Captain-facing failure summary and resume
  scheduling only after the real child reaches `idle`; the failed task is not
  automatically retried.
- Retain Alpha.2 client seams, role-owned Provider/model/reasoning policy,
  strict V2 state, trusted approval, quality gates, compact status, and the
  existing Windows wrapper integrations.

The fixed Alpha.2 `dsh-llm-retry` package is used only for development tests;
experimental upstream AgentTeams packages are not runtime dependencies.

No AUTO integration is restored.

# v0.1.15-desktop.1（Windows fork）

本 Windows fork 将 AgentTeams 上游 provenance 固定到提交
`232a338fc9a0d393f118912386f67e7f3a6c67d6` / 包版本 `0.1.15`。

## 变更

- 只在新的模型工具输入边界归一化空的可选任务字段；严格 V2 持久化读取
  仍然 fail-closed，不增加旧 Team/Profile 迁移层。
- 仅结算仍匹配当前 Team、成员、任务、attempt 和 `attemptId` 的最终
  `agent/error`；重复、迟到、转派、成员删除或 Team 替换事件不会写入状态。
- 保存有界且脱敏的队长失败摘要；真实子 Agent 进入 `idle` 后才恢复调度，
  不会自动重试失败任务。
- 保留 Alpha.2 客户端接口、角色级 Provider/模型/思考策略、严格 V2、受信任
  审批、质量门禁、紧凑状态以及现有 Windows 包装器集成。

固定 Alpha.2 的 `dsh-llm-retry` 仅用于开发测试；实验性上游 AgentTeams 包不进入
运行时依赖。不恢复 AUTO 集成。
