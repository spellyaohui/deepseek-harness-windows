# v0.1.14-desktop.9

- `agent_teams_create_task` now treats `assignee="captain"` as captain-owned work and normalizes blank or whitespace assignees to the shared task pool. Other non-empty values still require an active member with that exact name.
- Deliverable quality-gate failures now explain that implementations and repairs need concrete workspace-relative POSIX paths covered by `inScope`; abstract outcomes belong in the task subject, description, or acceptance criteria.
- Protected `.env`, secret, and `.git` paths remain excluded from `inScope` and deliverables, with an explicit safe-boundary explanation.
- Added quality-gate and lifecycle regressions for captain ownership, shared-pool normalization, actionable path guidance, and protected-path rejection.
