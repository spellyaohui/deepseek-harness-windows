# AgentTeams v0.1.14-desktop.3

This Windows fork release keeps the upstream AgentTeams v0.1.14 profile and
member lifecycle behavior while fixing the optional member-model default at
the desktop integration boundary.

## Fixed

- An omitted `memberModel` is represented by Schemastery as an empty string.
  The resolver now treats that value, including whitespace-only values, as
  omitted so ordinary members inherit the captain's current provider, model,
  and reasoning effort.
- The regression covers the real integration shape and prevents the runtime
  error `configured memberModel must not be empty` from returning.

## Verification

- `pnpm test` passes in `win-desktop/agent-teams-plugin`.
- `npm run verify:upstream` passes from `win-desktop` without installing
  dependencies or accessing the network.
- The Windows wrapper x64 NSIS and ZIP artifacts are rebuilt and inspected
  before distribution.
