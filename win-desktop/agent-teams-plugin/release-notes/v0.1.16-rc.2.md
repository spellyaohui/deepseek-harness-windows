# AgentTeams v0.1.16-rc.2 — unpublished candidate

This candidate was superseded by `v0.1.16-rc.3` after a Windows-only test-path issue. The supported Harness matrix remains `0.1.2-rc.1` (recommended), `0.1.2-alpha.5`, and `0.1.2-alpha.2`; npm uses the `next` channel.

The candidate introduced the existing-team continuation guidance, stable AgentTeams instructions, Web approval wake-up, and settled Team lock cleanup. The published replacement keeps those changes and the Windows fork's role routing, compatibility layer, quality gates, and durable-session gateway.
