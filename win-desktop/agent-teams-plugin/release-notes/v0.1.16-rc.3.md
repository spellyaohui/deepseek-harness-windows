# AgentTeams v0.1.16-rc.3

The recommended Harness host remains `0.1.2-rc.1`; `0.1.2-alpha.5` and `0.1.2-alpha.2` remain supported. This Windows fork upgrades only the AgentTeams plugin baseline and keeps the npm channel on `next`.

Changes carried into the fork:

- Duplicate creation directs the captain to continue the existing Team instead of ending it first.
- Web Approve & Run wakes the captain after durable approval commits.
- Settled in-process Team lock queues are released without changing serialization.
- Member sessions receive a fixed member-scoped prompt before their first request; captain-only guidance is not installed on AgentTeams children.

The local Team/Native routing policy, RC.1 compatibility adapter, per-role Provider/model/reasoning selection, strict V2 state, quality gates, and durable-session subagent gateway remain authoritative where upstream does not own those behaviors.
