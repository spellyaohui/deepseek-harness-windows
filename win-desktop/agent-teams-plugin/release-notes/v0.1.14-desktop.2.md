# AgentTeams v0.1.14-desktop.2

This Windows fork release keeps the upstream AgentTeams v0.1.14 profile runtime
and adds a persistent, restart-aware editor in the Harness-native settings
page.

## New

- **Editable profiles**: the existing `子智能体` settings section exposes
  profile descriptions, protocols, execution prompts, captain/seed planning,
  member routes, fallback behavior, task dependencies, and review policy.
- **Built-in delivery profile**: `software-delivery` provides analyst,
  implementer, tester, and reviewer roles and can be restored after edits.
- **Safe desktop persistence**: custom profiles and built-in edits are stored
  in the existing desktop settings file through a narrow IPC bridge. The host
  validates JSON-safe values and falls back to the built-in profile when stored
  data is malformed.

## Compatibility

- Profile changes take effect after restarting Harness; existing sessions keep
  their creation-time routing and settings.
- The local CPA model catalog, Team/Native routing, OpenCode compatibility,
  Session Markdown export, Windows process handling, and upstream lifecycle
  and quality-gate behavior remain owned by their existing components.
- Ordinary AgentTeams requests retain the wrapper's existing immediate
  execution default. Explicit profile calls continue to use the upstream
  resolver, DAG, snapshot, and lifecycle semantics.

## Verification

- `pnpm test` passes in `win-desktop/agent-teams-plugin`.
- `npm run verify:upstream` passes from `win-desktop` without installing
  dependencies or accessing the network.
- The Windows wrapper release gate and x64 NSIS/ZIP artifact checks are run
  before publishing a build from this fork.

# AgentTeams v0.1.14-desktop.2

本地 Windows fork 保留上游 AgentTeams v0.1.14 的 profile 执行语义，并在

- **可编辑 Profile**：在现有“设置 → 子智能体”中编辑描述、协议、执行提示、captain/seed 规划、成员路由、fallback、任务依赖和 review policy。

- Profile 修改需重启 Harness 后生效；已有会话继续保留创建时的路由和设置。
