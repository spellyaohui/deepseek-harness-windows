## Merge result

- Adopts the upstream semantic-token theme support: activity panels, cards,
  badges, task nodes, plan controls, and dialogs follow Harness light, dark,
  system, and custom semantic themes without a second theme store.
- Retains the 0.1.5 delivery and Session v3 architecture. Team work uses the
  upstream queue path; navigation and activity surfaces keep current behavior.
- Reapplies only local capabilities not solved upstream: the durable-session
  gateway; role Provider/model/reasoning policy; strict V2 persistence;
  quality contracts; shared model catalog; Team/Native routing; authenticated
  Web routes; Profile editor integration; and desktop regressions.
