## Behavior

- Import Unicode card identity, finding-line diagnostics, settled failure notes,
  artifact-bound verdicts, repair work-order/verification recovery and excluded
  finding escalation, durable fork lineage, source metadata and owner tool policies.
- Inline create-plan defaults use the same saved temporary policy as unbound
  add-member calls. Profile roles and explicit routes remain authoritative;
  default-shaped inputs do not silently select the captain's provider.
- Selected route, reasoning and source are frozen before writes. Owner policies
  retain four coordination tools and remain applied after staged approval or cold
  continuation. Profile and staged prompt edits preserve policy data.
- Preserve strict V2, no automatic migration, paired role routes, local quality
  audits, Chinese defaults, compact read-only status, CAS/auth, Team/Native
  separation and the serialized durable-session subagent gateway.
- The separate scripts/legacy-session-source-repair.mjs utility is retained for
  explicit operator use; startup and durable reads never invoke it.
