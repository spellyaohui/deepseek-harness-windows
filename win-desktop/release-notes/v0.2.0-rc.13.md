# v0.2.0-rc.13（本地安装包已构建，待发布）

在“设置 → 扩展设置 → 配置备份”新增密码加密导出/导入，包含模型供应商和
API Key / Token、图像输入和思考档位、临时子智能体、团队 Profile 角色路由及

保存和凭据接口；错误密码不写入，普通失败回滚，无法完整恢复时明确提示。
