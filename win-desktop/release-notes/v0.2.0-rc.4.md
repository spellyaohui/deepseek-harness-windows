# DeepSeek Harness Windows v0.2.0-rc.4

Harness remains pinned to official 0.2.0-rc.2 at 639ed015397290b3745d163aafe02ffee4aa3f84.

- Remove the OpenCode model-capability module and third-party capability probes.
- Offer Default plus Minimal, Low, Medium, High, Xhigh and Max; configure the explicit levels per model. Preserve existing wire mappings and draft cancellation.
- Replace automatic image input with image/text-only choices; new providers/models default to text.
- Group model-list actions, bulk input choices, expandable model settings and provider Save/Cancel. Keep discovery and credentials handling.
- Models 0.2.0-rc.2-desktop.3 and CPA 0.1.11 preserve manual settings through Save/startup; official Harness/AgentTeams revisions do not change.

Validation completed on 2026-10-01:

- The full offline, install-free `npm run verify:upstream` gate passes: Models 25/25, CPA 27/27, all AgentTeams suites, wrapper 149/149; 890 production packages and no RC.1 cohort.
- Unpacked and ZIP runtime closure checks pass (868/867 packages; no RC.1 cohort). The ZIP contains 29,389 entries and matches 1,041 package/app manifests against the unpacked app.
- All 30 Models and 10 CPA runtime JS/CSS artifacts match the freshly built local outputs. Neither the retired OpenCode plugin nor the capability-probe Remote is packaged.
- The packaged app starts with a fresh isolated Home and passes authenticated `llm/listProviders`. No real user configuration, credential or live model endpoint is used.
- Real browser checks cover Save/Cancel, preserved per-model fields, text defaults, seven reasoning choices with no extra Off option, light/dark themes and a 400px viewport without control overflow or console errors.
