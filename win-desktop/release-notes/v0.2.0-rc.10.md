# DeepSeek Harness Windows v0.2.0-rc.10

Harness 保持 **0.2.0-rc.2**。本版汇总 rc.2 之后的桌面修复与功能调整。

- 模型设置移除 OpenCode 手工能力校验和第三方自动探测。思考强度采用 Default、Minimal、Low、Medium、High、Xhigh、Max 七档，每个模型可手动选择支持的档位。图像输入改为图像/仅文本两种选择，新模型默认仅文本。
- 整理模型供应商编辑器布局，并将扩展设置、AgentTeams 字体与控件尺寸对齐官方设置页面。
- 修复 AgentTeams 保存被桌面默认配置覆盖、重试保存按钮换行的问题。内置软件交付团队及成员提示词改为中文，补全职责说明。
- Team 模式的队长原生 subagent 调用接入团队成员和任务调度，保留角色模型与思考策略、生命周期和质量门禁。
- “桌面”改为“扩展设置”，加入 DSH 内置 web_search/web_fetch 开关。自动保存，完整退出并重启后生效，不影响独立 MCP 工具。
- 修复关闭工具后，旧的 `web: disabled: true` 配置导致标准/PTC/创造预设加载失败。保留用户配置，只解除已关闭工具的服务依赖。
- 补齐干净机器构建输入、逐包 SHA-256 验证和 Windows 自动构建/安装后首次启动验收。详见仓库 `docs/CLEAN_WINDOWS_BUILD.md`。

普通使用下载 **EXE 安装包**，或 ZIP 绿色版。`Build-Inputs` 仅供重新编译源码，安装和运行不需要下载它。安装包未签名；使用模型需要自行配置账号或供应商凭据。

完整离线门禁通过，包装器 164/164。本版 EXE/ZIP 来自 [干净 Windows 源码构建](https://github.com/spellyaohui/deepseek-harness-windows/actions/runs/36823482174)，并通过 [第二台 Windows 机器的实际安装与桌面启动验收](https://github.com/spellyaohui/deepseek-harness-windows/actions/runs/36825551884)：模型目录、AgentTeams 保存/重启、联网工具开关和旧禁用配置下全部预设均正常，渲染器异常为零。未发出真实模型请求。
