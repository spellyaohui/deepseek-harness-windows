# DeepSeek Harness Windows v0.2.0-rc.3 (Windows x64 local build)

Status: complete offline acceptance and local packaging verification passed.

The desktop version is `0.2.0-rc.3`. Official Harness remains pinned to
`dsh-v0.2.0-rc.2` at `639ed015397290b3745d163aafe02ffee4aa3f84`;
AgentTeams remains `0.1.22-desktop.1`.

Fix model capability probing in Settings → Models. The local Models fork
previously supplied the old strict-codec `schema` field, so the official
Harness 0.2 Typert registry rejected the Remote contribution and the editor
reported that Host Remote was unavailable. Models `0.2.0-rc.2-desktop.2`
supplies the required lazy `create()` factories and checks the contribution
and mount call against their actual TypeScript contracts.

The new regression exercises the official Client Gateway and Typert registry:
Remote registration, late namespace lookup, probe routing, cancellation,
disposal, and strict request/result validation. Probes still change only the
unsaved draft; the parent Save action persists settings.

The complete offline gate passes: Models 52/52, CPA 27/27, full AgentTeams
suites, local artifact synchronization, the source runtime dependency closure,
and wrapper 150/150. Same-commit archive recovery preserves the immutable
original release hash records and records all 650 actual rebuilt hashes and
their lock integrities. No regression is skipped or weakened. Details are in
[`SOURCE_ARCHIVE_REBUILD_20260930.md`](../../docs/SOURCE_ARCHIVE_REBUILD_20260930.md).
The unpacked runtime resolves 869 production packages. The ZIP resolves 868
and all 1,042 package/app manifests match the unpacked build. The packed versions
are wrapper `0.2.0-rc.3`, Harness `0.2.0-rc.2`, Models
`0.2.0-rc.2-desktop.2`, and AgentTeams `0.1.22-desktop.1`. Compiled codec
factories and the official whale icon bytes were checked. With a fresh isolated
home directory, the packed Host started and successfully served an authenticated
`model-capabilities/probe` RPC. The unsupported verification protocol produced
eight `not-applicable` checks; no live provider call or settings save was made.

Build dependencies were recovered against the fixed lockfile. Downloads of
large Windows-native components stalled; incomplete files were preserved and
replaced by matching-version packages from the SHA-256-verified rc.2 release
ZIP. The full offline gate was rerun successfully after this recovery. Electron
44.0.0 was reused from that verified ZIP without its old `resources/app`, and
the wrapper was packaged from a real `node_modules` directory.

The installer is `NotSigned`. No installation, commit, push, tag, upload or
GitHub publication was performed.
