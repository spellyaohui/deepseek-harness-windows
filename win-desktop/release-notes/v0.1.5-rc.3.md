# DeepSeek Harness Windows v0.1.5-rc.3

## Scope

- Windows wrapper patch release. The embedded official Harness baseline remains
  `dsh-v0.1.5-rc.1` at `183f08e9c6dde7e36cd2318eaee70b0da08fb35e`;
  every fixed local tarball reference remains on that host release.
- AgentTeams remains based on upstream `v0.1.18` at
  `68fe529d602b1eea1f1ecaee99857d20a4f94be0`; the desktop fork is
  `0.1.18-desktop.1`.

## Fixed

- Blank or whitespace-only captain `claim_task.assignee` is equivalent to an
  omitted property. Non-empty member names are trimmed before lookup.
- The captain prompt now separates create/reassign ownership syntax from claim
  syntax while remaining within its 3,500-character limit.
- Default-depth member creation no longer submits Harness 0.1.5 scope-local
  `subagent` through the child `toolFilter` to global-only `tools.restrict()`.
  This fixes claimed tasks remaining on `idle/unspawned` members while keeping
  Team execution guards and durable gateway depth enforcement intact.

## Boundaries retained

- `assignee="captain"`, unknown members, unauthorized claims, and missing
  quality evidence remain strict no-write failures.
- AgentTeams still owns task state, scheduling, and the activity panel; all
  continuable child operations still cross the durable subagent gateway.
- No tools, Team state, successful output schema, gateway API, official Harness
  package, or fixed tarball changed.
