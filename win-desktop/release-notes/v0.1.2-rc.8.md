# DeepSeek Harness Windows v0.1.2-rc.8

## 周期用量额度耗尽分类修复

- 修复官方返回 `You've reached your weekly usage limit...` 时被误分类为普通 `RATE_LIMIT`、进入默认重试循环的问题。
- Windows loader 仅在官方 `dsh-llm` 模块边界补充明确的小时/日/周/月/季度/年用量限制达到、超出或耗尽语义，并保留官方其余分类逻辑。
- 普通瞬时 429 限流仍可重试；只有额度重置通知不会被误判为已耗尽。

## 验证

- `npm test`：132 项通过。
- `npm run verify:upstream`：Models、CPA、AgentTeams、Session Markdown、运行时闭包和 wrapper 回归全部通过。
- 官方运行时基线仍为 `dsh-v0.1.2-rc.1` 固定提交；本次只更新 Windows 包装器兼容层。

安装包未进行 Authenticode 商业签名（`NotSigned`），Windows SmartScreen 可能显示额外警告。
