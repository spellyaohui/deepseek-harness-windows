# DeepSeek Harness Windows v0.2.0-rc.9

- 将“桌面”设置改名为“扩展设置”，保留窗口关闭行为并添加内置联网工具开关。
- 内置 web_search / web_fetch 默认开启；关闭后重启应用生效，覆盖宿主、所有 Agent 预设与后续成员的官方工具注册及提示。
- 保留底层 web 服务、用户预设配置和独立 MCP 工具。启用开关不会覆盖用户预设里已有的单独禁用设置。
- 设置自动保存；保存中禁用控件，失败时恢复此前状态并显示错误。
- Harness 保持 0.2.0-rc.2，AgentTeams 保持 0.1.22-desktop.4，Desktop Settings 更新为 0.1.4。
