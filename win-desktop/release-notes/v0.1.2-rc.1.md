# DeepSeek Harness Windows v0.1.2-rc.1

## 核心升级

- 运行时迁移到官方 `dsh-v0.1.2-rc.1` 固定提交 `a66e4702047846cdaa10c66c9d3df3951f5ea70d`。
- 官方源码使用 pnpm `11.7.0` 完成构建，分别打包 9 个 vendor 与 242 个 dsh 包，并通过 packed-install 验证。
- Wrapper 只引用上述 251 个固定 tarball；包名、版本、family 和 SHA-256 记录在 `docs/UPSTREAM_RC1_SOURCE_MANIFEST.md`。

## 本地能力保留与迁移

- Models fork 基于 Alpha.2 provider-card/footer、Onboarding 和 Remote 架构重建，继续提供每模型 `auto / image / text-only`、显式协议、容量、reasoning 与兼容字段编辑。
- 统一能力探测继续按当前 Provider、地址和协议串行运行；认证、代理认证、超时、限流、5xx 与网络错误保持 inconclusive，只有明确覆盖才替换现有能力字段。
- CPA、OpenCode、CommandCode、WOYAOPRO 与自定义 Provider 继续共享同一 provider-neutral 模型目录；Provider 特异规则没有进入 Models fork。
- AgentTeams 更新到 `0.1.14-desktop.12`，适配 Alpha.2 client seams，并迁入经过验证的 wait、身份作用域、Revision/CAS 和活动事件恢复结构。角色级 Provider/模型/推理策略、严格 V2、质量门、紧凑状态、Team/Native 路由和桌面 Profile 编辑保持本地 Owner。
- AgentTeams 生命周期边界增加无 Team 审批保护：只有已确认的 `active=true + phase=staged` 才能审批；“继续/确认”在没有 staged Team 时返回 inactive 引导，不隐式创建或写入状态。
- “插件 → 插件配置”隐藏了与独立“子智能体”设置页重复的原生 Subagent 卡；官方 Subagent 服务、已有设置和 AgentTeams 成员运行链保持不变。
- Windows Wrapper 保留通用 `grep` 精确归一化、OpenCode/Kimi Schema 与流兼容、`x-opencode-session`、隐藏控制台、启动 healing、Desktop Settings 和 Session Markdown。
- Windows Wrapper 会完整接收 Alpha.2 `dsh web:` 输出中的一次性认证 URL，再交给 Electron 建立签名 cookie；不会再因只打开无 token 的 loopback 根地址而显示认证黑屏。
- Windows CreateProcess 隐藏重写迁移到 Alpha.2 的 `dsh-win32-process` 实际 Owner 边界。
- CPA `0.1.7` 在 TypeScript 编译前脱离可能被 Windows 消费者或索引器映射的旧 `lib` 输出，避免发布门禁因 `TS5033` 文件占用错误中断；回归保证文件内容和消费者持有的旧硬链接不被破坏。

## 明确排除

- AUTO 继续完全移除。
- 不增加旧 Team、旧 Profile 或旧对话兼容迁移层。
- 不直接安装 Alpha.2 的 AgentTeams experimental 包。

## 发布门禁

- `npm run verify:upstream` 必须离线、无安装、无网络、无打包并退出 0。
- `npm run dist:win` 必须从真实 `node_modules` 构建出 `win-unpacked`、NSIS EXE、ZIP 和 blockmap。
- `scripts/verify-alpha2-runtime-closure.mjs` 必须从源码与包内 `src/dsh-service.js` 使用 `createRequire` 解析完整生产闭包，以及 `dsh-app-boot`、Cordis loader/include、`js-yaml` 和 `argparse`；`scripts/verify-alpha2-zip-closure.mjs` 还必须拒绝不安全归档路径，并证明 ZIP 与 `win-unpacked` 的 package manifests 字节一致。
- 用户人工安装验收前不提交、不推送、不打 tag、不创建 GitHub Release、不上传资产。
