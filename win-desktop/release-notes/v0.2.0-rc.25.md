## 修复与保留

- rc.24 在干净 Windows CI 未通过，保持未发布草稿；不沿用它的包或测试结论。
- 原子 idle 调度写入遇到 Windows 共享锁后，原实现只警告且丢失后续派发机会。
  使用官方成员释放事件提供第二次机会；状态观察按子会话顺序处理，Team 锁内
  校验最新状态和精确 live Agent，旧事件不停车、不发通知、不派发。
- 独立复核发现并修复创建失败释放循环：只有精确 Agent 的真实 idle 事件才
  授予释放补调度。真实冷恢复创建拒绝回归 RED→GREEN，不无限消耗 attempt。
- 不扩大原子写重试预算、不直接覆盖文件、不自动重跑已执行的 open attempt；
  队长跨轮接管、质量门、冻结角色权限与模型/思考、唯一 durable gateway 全保留。
  长期存储故障仍报错，可能需要显式恢复；不宣称无限自动恢复。
- 前台完成测试等正常 durable idle 收尾后取基线，仍完整检查越权消息零 Team
  写入、零邮箱追加、零模型唤醒。有限警告进入测试诊断，失败不再缺失原因。
- 累计改进、有效所有者与退役能力见 [保留索引](../../docs/CONVERSATION_CAPABILITY_RETENTION_20261014.md)。
  用户自行切换 Profile；安装/发版不修改现有配置、会话或凭据。
