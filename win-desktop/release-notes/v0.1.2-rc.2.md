# DeepSeek Harness Windows v0.1.2-rc.2

## AgentTeams 自动委派

- 普通子智能体委派默认使用 `approval="automatic"`。主模型省略 Team
  名称，由 AgentTeams 根据目标生成隐私安全名称，并自行创建任务名称、
  质量契约与依赖。
- 只有用户明确要求“启动前先审计划”时才使用 `approval="required"`；
  staged 人工审核和显式批准边界没有被削弱。

## Web staged 修复与安全门禁

- 修复成员编辑、任务新增/保存/删除遗漏 `planRevision`，导致
  `staged plan update requires revision-aware options` 的问题。
- Activity snapshot、浏览器请求、Host CAS 和 Web 一次性审批凭据现在使用
  同一个 revision；过期页面不能覆盖新计划。
- 补齐上游 AgentTeams `v0.1.15` 的 Alpha.2 Connection 认证及
  Host/Origin 检查。未认证、跨站来源和 Connection 未就绪均 fail closed。
