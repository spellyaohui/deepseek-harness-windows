# DeepSeek Harness Windows v0.1.5-rc.2

## Scope

- Windows wrapper patch release. The embedded official Harness baseline remains
  `dsh-v0.1.5-rc.1` at `183f08e9c6dde7e36cd2318eaee70b0da08fb35e`; every
  fixed local tarball reference remains on that host release.
- AgentTeams remains upstream `v0.1.18` at
  `68fe529d602b1eea1f1ecaee99857d20a4f94be0`.

## Fixed

- The Team routing policy no longer passes official scope-local `subagent` to
  the global-only `tools.restrict()` API. Globally registered native delegation
  tools remain hidden for Team work. The scope-local schema remains visible as
  required by Harness, but a Team-scoped execution guard rejects its execution;
  Native routing still executes it.
- `agent_teams_claim_task` continues to reject
  `assignee="captain"`, because that property is not a claim operation. The
  error now gives a recoverable next step: omit `assignee` to claim an existing
  captain-owned task, or use `agent_teams_reassign_task(assignee="captain")`
  before captain takes over member-owned work.

## Quality contract retained

- implementation/repair completion continues to require a `commandsRun` entry
  with `status="passed"` for every declared `verify` command. A missing record
  is intentionally rejected; this release does not weaken the quality gate.
