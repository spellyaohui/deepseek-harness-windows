# DeepSeek Harness Windows v0.1.2-rc.7

## 子智能体统一网关并发收口

- 连续子 Agent 的启动、续接消息、打断、退休和冷恢复统一经过 durable Session 子智能体网关；只接受当前真实在线 Agent，旧句柄、同 ID 伪句柄和已退休成员会在调用前拒绝。
- 删除、任务重分配、审批失败、启动异常清理及停止操作都使用每子 Agent 锁；interrupt 与 drain 保持在同一锁内，停止边界不会插入新的投递。
- 新增并发停止/drain 回归，验证已进入网关的投递先结算、再静默等待，随后冷恢复仍受退休索引保护。
