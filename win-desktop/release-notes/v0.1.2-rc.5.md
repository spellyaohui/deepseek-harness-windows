# DeepSeek Harness Windows v0.1.2-rc.5

## 子智能体统一网关

- 连续子 Agent 的启动、续接消息、打断、退休和冷恢复统一经过 durable Session 网关。
- 网关只接受当前真实在线 Agent；同 ID 旧句柄、伪句柄和退休竞态会在调用前拒绝，并按子 Agent 锁串行化操作。

## RC.1 模型路由保持

- 在官方 `dsh-v0.1.2-rc.1` 的 `agent/created` 生命周期下，角色级 Provider、模型和 reasoning effort 在首次、后续、并发和冷恢复请求中保持有效。
