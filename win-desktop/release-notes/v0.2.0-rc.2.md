# DeepSeek Harness Windows v0.2.0-rc.2 (Windows x64 prerelease)

- Pin the official Harness `dsh-v0.2.0-rc.2` source at `639ed015397290b3745d163aafe02ffee4aa3f84` and AgentTeams `v0.1.22` at `9cba4fe4171f27c019991cafd2a107f87ef3517b`.
- Use the complete official 0.2.0 package graph, including its plan review, model search, sidebar, terminal, plugin guidance, model catalog and opt-in asynchronous questions. Keep the official Native Subagent page separate from AgentTeams role settings.
- Retain local role routing, strict V2, quality gates, the durable child-operation gateway, authenticated Web/CAS, provider-neutral Models extensions, CPA, and narrow wrapper compatibility rewrites where upstream has no equivalent.
- Add a manual tray action for the official Windows `dsh` command-ownership protocol. It never edits PATH on startup; an installed launcher and explicit user confirmation are required. A system-PATH command that a user-PATH install cannot supersede is rejected before mutation.

The source migration was followed by a local acceptance build on 2026-09-30. EXE, ZIP and blockmap were produced without a code-signing certificate; the packed runtime and ZIP dependency closures, embedded CLI version, icon asset, and an isolated unpacked-app startup were checked. Installation subsequently completed: all 25,783 installed files match the unpacked build in size and SHA-256, and the installed runtime dependency closure passes. An earlier interrupted installation succeeded with the same EXE after the user paused Kaspersky; no specific interception rule has been established.

The user confirmed the local build was ready and authorized publication on 2026-09-30. This release reuses the same tested EXE, ZIP and blockmap, without rebuilding or overwriting the installed app. Publication checks do not claim additional independent live-provider/subagent, installed PATH-command or endurance test results. Rebuildable plugin `lib` output is retained locally but excluded from source control; the offline gate builds and synchronizes it before packaging. Verification evidence and limits are recorded in `docs/UPSTREAM_MAINTENANCE.md`.

## 发布前验证

- 完整离线 `npm run verify:upstream` 再次通过：Models 50/50、CPA 27/27、AgentTeams 全套、Windows wrapper 149/149。
- `win-unpacked` 解析 869 个生产依赖；ZIP 解析 868 个生产依赖，1,042 份包/应用清单与打包目录一致。官方 Harness、AgentTeams 和 Models 版本及官方鲸鱼图标核对通过。
- 安装包未作 Authenticode 签名（`NotSigned`），可能出现 Windows SmartScreen 或安全软件提醒。本次发布未禁用、配置或添加安全软件白名单。
- 安装中途退出与卡巴斯基运行状态有关，但没有确认具体拦截规则；用户暂停后用同一 EXE 安装完成。
