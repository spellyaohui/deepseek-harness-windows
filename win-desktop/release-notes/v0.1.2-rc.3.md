# DeepSeek Harness Windows v0.1.2-rc.3

## AgentTeams 普通委派

- 普通 `captain-planning` 委派默认使用 `approval="automatic"`。
- 主模型省略 Team 名称，由插件生成安全名称，并通过 AgentTeams 任务工具自动建立任务名称、质量契约和依赖。
- 不再要求用户在 Web 页面输入任务名称或确认普通任务启动；只有用户明确要求启动前审查计划时才进入 `approval="required"` staged 流程。

## staged Web 编辑状态门禁

- 修复 Team 在 `building` 或等待对话反馈时，Web 页面提前暴露成员/任务编辑控件的问题。
- 这些状态现在只允许查看、返回对话或放弃计划；成员编辑、任务新增/保存/删除和批准会在界面层禁用。
- `ready_for_review` 仍通过 `planRevision`、Host CAS 和一次性 Web 审批凭据完成编辑与批准。
