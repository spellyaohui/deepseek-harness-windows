# DeepSeek Harness Windows v0.2.0-rc.18 — 子智能体路由修复

Status: local EXE, ZIP and blockmap built and verified; no GitHub tag or Release created.
Harness remains 0.2.0-rc.2; AgentTeams local fork is 0.1.22-desktop.11.

## Fix

Both 队长规划 and 固定任务模板 keep Profile role model/reasoning policies.
Unbound custom members now share the saved 临时与自定义子智能体 default with
captain `subagent` calls. Explicit arguments and frozen role inheritance win;
`role_template` lets renamed members bind an exact existing Team role. Invalid/
unavailable selections fail before writes/spawns rather than using the captain route.

Member cards show reasoning policy and configuration source, including active
fallback routes. Draft controls retain official typography and layout. Prompt-only
staged edits no longer change source labels; each settings editor has a unique key.
Existing Teams keep their frozen routes and prompts, including after restart.

## Validation

- Complete offline `npm run verify:upstream` passed before version synchronization.
- Focused real-runtime routing/native compatibility regressions: 32/32 passed,
  including both planning modes, approval, concurrency and cold continuation.
- Isolated actual source components in headless Edge: policy labels and both
  planning choices pass; no horizontal overflow at 320/560/800px and no renderer/
  console errors. External model/Settings services and unused brand data are fixtures.
- Final synchronized full gate passed inside the unchanged `npm run dist:win`
  entrance: all plugin/runtime regressions and wrapper 194/194 pass.

The first packaging gate stopped on one foreground native-compatibility test's
`team.json` replacement EPERM in its isolated Temp directory. Prior committed state
remained intact; no package was generated by that failed run. Re-running the same
gate and assertions passed. By the subsequent lock inspection the fixture file had
been cleaned up, so no responsible PID was identified and no process was terminated.
This does not prove the rc.17 intermittent Windows file-occupancy issue is eliminated.
