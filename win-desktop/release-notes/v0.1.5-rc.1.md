# DeepSeek Harness Windows v0.1.5-rc.1

## Upstream baseline

- Pins official Harness `dsh-v0.1.5-rc.1` at commit
  `183f08e9c6dde7e36cd2318eaee70b0da08fb35e`.
- Uses the complete fixed local 0.1.5 tarball closure, including Session format
  v3, common file upload, resources/sidebar, HTTP proxy support, and current
  Web/startup packages.
- Pins AgentTeams `v0.1.18` at commit
  `68fe529d602b1eea1f1ecaee99857d20a4f94be0`, whose recommended host is
  Harness `0.1.5-rc.1`.

## Compatibility ownership

- Where 0.1.5 already hides normal Node subprocess windows, the wrapper accepts
  the upstream implementation. It adds only the missing preload handoff for
  the Windows Job runner, so its native `CreateProcessW` target (including
  `pwsh`) receives the established hidden STARTUPINFO configuration.
- AgentTeams adopts upstream 0.1.18 atomic planning, lazy member start,
  mailbox de-duplication, attempt recovery and cleanup. The local gateway
  adapts 0.1.5 `deliverPrompt` queue/steer delivery and Session v3 routing
  without permitting a direct child-operation bypass.
- The provider-neutral Models and CPA paths retain their local input,
  capability-probe, reasoning, and persistence contracts only where upstream
  has no equivalent.
- The wrapper keeps its narrow grep argument repair and bounded-period QUOTA
  classifier; both remain fail-closed for non-target inputs.

## Runtime closure

- Adds the exact 0.1.5 UI-primitives runtime imports to the flat Windows
  dependency closure, preventing the Models settings client from failing on
  missing UI dependencies at startup.
- AUTO remains absent from dependencies, patches, UI, prompt, and migration
  paths.
