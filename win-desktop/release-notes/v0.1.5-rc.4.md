# DeepSeek Harness Windows v0.1.5-rc.4

## Scope

- Windows wrapper patch release. The embedded official Harness baseline remains
  `dsh-v0.1.5-rc.1` at `183f08e9c6dde7e36cd2318eaee70b0da08fb35e`;
  every fixed local tarball reference remains on that host release.
- AgentTeams remains based on upstream `v0.1.18` at
  `68fe529d602b1eea1f1ecaee99857d20a4f94be0`; the desktop fork is
  `0.1.18-desktop.1`.

## Fixed

- Before the canonical token URL is loaded, the wrapper removes only stale
  `dsh-auth-*` Cookies for `127.0.0.1`. This prevents random-port authentication
  Cookies from accumulating into a request header that makes the long combined
  `/plugins/` request fail with HTTP 431.
- If the current loopback service still returns 431 for `/plugins/`, the wrapper
  repeats that narrow cleanup and reloads the same canonical token URL once.
  A one-shot guard prevents a recovery loop.

## Boundaries retained

- Other loopback Cookies, other domains, caches, sessions, settings, and
  credentials are untouched. The token URL is neither persisted nor logged.
- No AgentTeams behavior, gateway API, official Harness package, fixed tarball,
  or dependency changed.
