# DeepSeek Harness Windows v0.1.5-rc.5

## Scope

- AgentTeams is updated to local `0.1.19-desktop.1`, based on upstream
  `v0.1.19` at `6ef77bff4893fb22bd5ba39cb6b2c5693eba85be`.
- The official Harness source closure remains `dsh-v0.1.5-rc.1` at
  `183f08e9c6dde7e36cd2318eaee70b0da08fb35e`; its fixed tarball identities
  and host peer ranges are unchanged.

## Changed

- Use upstream member-start recovery for explicit host tool-filter rejection,
  repair-scope inference, and captain-only task amendment.
- Retain the Windows unified durable gateway for member start, queue/steer
  delivery, interrupt, retirement, and drain. Strict V2, role routing,
  Team/Native, quality, Profile, and authenticated Web/CAS behavior stay local.

## Boundaries retained

- No runtime user data is modified.
- This source release note records no installer, package, or release artifact;
  packaging and live acceptance remain separate authorized gates.
