# DeepSeek Harness Windows v0.2.0-rc.5

Fix saving the AgentTeams Team/Native setting: the desktop inserted its plugins
after the profile's editable layer, so the official configuration editor skipped
the change and reported a home/command-line override. The desktop now contributes
only its four owned plugin insertions beneath profile, Home and CLI edits. It
does not rewrite user files or bypass the official overlay/refusal or revision guards.

The pinned app-boot composition seam is scoped, idempotent and fails on source
drift. It applies only to the desktop Web profile; headless/custom profiles are
unchanged. Each plugin retains its own package and behavior.

Harness remains official 0.2.0-rc.2, AgentTeams 0.1.22-desktop.1, Models
0.2.0-rc.2-desktop.3 and CPA 0.1.11. The rc.4 manual model settings stay included.

The regression reproduced the original error before the fix. It uses the actual
Loader, SettingsForms, ConfigEditor and AgentTeams schema without starting a
server or accessing a network. Save, restart, retained profiles/unrelated fields,
stale revisions, Home/CLI refusal, narrow admission and composition drift pass.
The full isolated Electron Host also saves via authenticated settings/replace,
retains Native after restart, saves Team again and reads the provider list.

The full offline, install-free `npm run verify:upstream` gate passes: Models 25/25,
CPA 27/27, complete AgentTeams suites, wrapper 152/152, and 890 production packages
with no RC.1 cohort. The packaging entry point reran the same gate successfully.

Packaged validation on 2026-10-01:

- Unpacked closure: 868 production packages, no RC.1 cohort.
- ZIP closure: 867 packages, 29,390 archive entries and 1,041 matching package/app manifests; no RC.1 cohort.
- The exact packaged Electron program passed authenticated AgentTeams Save, restart persistence, second Save and provider-list RPC with a fresh isolated Home. No real user settings, credentials, Teams or provider request were used.
- The three changed wrapper runtime modules match source bytes. Packaged wrapper/Host/plugin identities and binary FileVersion match the pinned versions above.
