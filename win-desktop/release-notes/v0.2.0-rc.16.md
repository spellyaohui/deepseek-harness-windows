# v0.2.0-rc.16（本地安装包已构建，待发布）

2026-10-06。AgentTeams 更新为 0.1.22-desktop.9，Harness 保持 0.2.0-rc.2。

- AgentTeams：队长接管跨回合保留；验收证据逐条匹配；Git 工作树快照核对变更清单；
  编号成员继承角色提示词；`amend_task` 拒绝合同外字段；integration 等待全部审查通过；
  输出截断向队长报告原因。详见 `agent-teams-plugin/release-notes/v0.1.22-desktop.9.md`。
- 新增包装器插件 `dsh-output-limit-finish`：通过官方 `llm/stream` 扩展点，把“上报为 stop
  但输出已用满本次 maxTokens（或模型默认上限）”统一改为官方 `max-tokens` 结束原因。
  与网关、provider、模型名称无关，cli2api、workbuddy、cursor-api、CPA 等网关都适用。
  模型声明的输出上限本身仍由用户在设置中调整。
- 按用户要求移除 OpenCode 兼容：pi-ai 结束原因恢复、`x-opencode-session`、Kimi Schema
  改写与 `model-fetcher` 目录同步全部删除，回归改为断言不得恢复。
- 其中三处缺陷来自上游 AgentTeams v0.1.22，不提交上游 PR，作为后续上游刷新时的首要对照点。
- 工具调用提示词 `0.1.1`：参数校验失败是调用参数写错，应按错误提示补正字段后重试，不得说成工具故障
  （会话中队长漏传 `ask_user_question` 的 `questions[0].id`，却向用户报告“工具内部错误”）。
  仍与 provider/模型无关，长度不超过 500 字符。

打包前分别核对：npm `@deepseek-ai/dsh` latest 仍为锁定的 0.2.0-rc.2（0.2.1-alpha.1
为 alpha 通道，未采用），`@nanmicoder/dsh-agent-teams` latest 仍为 0.1.22。
`dist:win` 内置的完整离线 verify:upstream 通过（Models、CPA、AgentTeams 全套及 189 项
包装器测试）。

新插件、工具调用提示词 0.1.1 与 AgentTeams 编译产物和打包内容逐字节一致；AgentTeams 清单仅被 electron-builder
去除 `bugs`、`keywords`、`scripts` 字段，版本、入口、导出和插件声明不变。打包内不含
`model-fetcher.js` 或任何 OpenCode 代码。EXE 图标为官方鲸鱼。
