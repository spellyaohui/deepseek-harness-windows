# DeepSeek Harness Windows v0.1.2-rc.4

## AgentTeams 编号角色模型继承

- 动态新增的 `reviewer2`、`reviewer3`、`reviewer4`、`reviewer5`、`reviewer6`，以及 `analyst`、`implementer`、`tester` 的编号成员，会从当前 Team 冻结的未编号基础角色快照继承 Provider、模型、reasoning mode 和 explicit reasoning effort。
- 支持 `reviewer-2`、`reviewer_2` 和 `reviewer 2` 等分隔写法，并支持继续增长的正整数后缀。
- 显式 Provider/模型/思考参数优先；没有匹配的自定义角色保持队长路由，角色描述出现多个候选时拒绝随机选路由并要求显式配置。
- 修复 `agent_teams_add_member` 模型调用边界：省略 `reasoning_mode` 时不再被 schema 默认值伪装成显式 `target-default`，编号角色能够正确继承基础角色模型。
