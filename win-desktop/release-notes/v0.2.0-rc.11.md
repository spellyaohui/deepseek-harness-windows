# DeepSeek Harness Windows v0.2.0-rc.11（待发布）

Harness 保持 **0.2.0-rc.2**。本机已生成 EXE、ZIP 和 blockmap，尚未发布到 GitHub Releases。

- 设置 → AgentTeams 团队新增“临时子智能体”默认 Provider、模型和思考策略。Team 模式支持连续、并发调用多个临时成员；Profile 角色路由与 Native 设置保持独立。AgentTeams 本地包为 `0.1.22-desktop.5`。
- Windows 控制台补丁补齐同步 `execSync` 和合法空 options 参数的覆盖。保留显式显示选项、原生参数校验、回调、输出及非零退出错误，并保持调用方 options 不变。

验证：完整离线 `npm run verify:upstream` 通过，包装器 **167/167**，无跳过；控制台专项在 Windows Node 24.19、Node 26.7 和实际 Electron 44 中均 **19/19** 通过。真实隔离 Electron MCP 实例经 npm `.cmd` 成功启动 CodeGraph 并完成握手，创建 CMD 的原生选项为隐藏。独立代码复核通过。

包内闭包通过：`win-unpacked` 868、ZIP 867 个生产包，1,041 份包清单一致。121 份包装器及本地插件运行文件与源码一致；实际包内 Electron 通过三组新增控制台参数/原生边界回归。构建及安装验收脚本现在读取当前源码版本，保留 rc.10 历史验收的显式版本校验。

现有证据确认补丁覆盖缺口，尚不能把用户看到的瞬时黑窗归因于 CodeGraph。rc.11 尚无第二台干净机器的实际安装验收结果；最新已发布安装包仍为 rc.10。
