# DeepSeek Harness Windows v0.2.0-rc.12（待发布）

Harness 保持 **0.2.0-rc.2**；AgentTeams 本地包为 **0.1.22-desktop.6**。

- 修复临时子智能体指定模型保存后回读成跟随队长。
- 模型“仅文本 / 图像输入”与官方控件统一为 14px 字号、20px 行高；Models 本地包更新为 `0.2.0-rc.2-desktop.4`。
- Profile 角色配置统一经官方设置文件和修订校验保存；新团队与页面一致，旧团队及编号角色保持创建时路由。
- 旧桌面记录保留。曾遇到覆盖问题时，可在 Profile 配置点击“导入桌面保存配置”，检查草稿后保存，再创建新团队。导入不会直接改配置，也不会写回旧 JSON。
- 提示词首尾换行和缩进保持原文；删除最后一个自定义 Profile 后仍可保存或重新加载；外部修改冲突时保留草稿。
- Windows 隐藏补丁传入 MCP 过滤环境、npm shim、捆绑 Node、子孙进程和 Worker，不修改系统环境变量。真实 CodeGraph 的两处 Git 调用已验证收到隐藏选项。
- 修复随机端口选中 `6697` 等 Chromium 禁用端口时的启动失败；本地端口探测仅绑定回环地址，错误提示隐藏临时认证 Token。
- 需求依赖错误列出实际任务 ID、状态及重试方法，仍须等待需求通过。

验证：完整离线 `npm run verify:upstream` 通过，包装器 **195/195**，无跳过；实际 Electron 44 页面通过保存、回读、重启、四角色路由、导入、冲突及 320/560/800 宽度检查，渲染错误 **0**。控制台后代专项在 Node 24.19、Node 26.7、Electron 44 中均 **15/15**；新增端口及诊断回归 **7/7**。

DSH 的隐藏补丁只覆盖自身进程树。排查也捕获了 Codex 所属 CodeGraph 的 Git 闪窗；该宿主需要单独配置，不能据此宣称 DSH 补丁覆盖所有程序。

本机构建于 2026-10-03 完成，尚未发布到 GitHub Releases。win-unpacked 解析 **868** 个生产包，ZIP 解析 **867** 个，**1,041** 个包与应用清单一致；**124** 个包装器和本地插件运行文件与源码字节一致。包内 Electron 通过 3 个原生控制台回归组、15 个后代回归和 7 个端口/诊断回归。

使用独立 DSH_HOME 和 Electron user-data-dir 实际启动包内 GUI 三次，验证临时模型及 Profile 保存/回读/重启、Models 目录、内置联网工具关闭、旧 disabled Web 配置下的预设健康及用户 Patch 原文保留，渲染异常 **0**。这项本机隔离验收不代表第二台干净机器安装或真实第三方模型请求验收。

本次重新构建已包含“仅文本 / 图像输入”的字体修正：14px 字号、20px 行高，Models 包为 `0.2.0-rc.2-desktop.4`。
